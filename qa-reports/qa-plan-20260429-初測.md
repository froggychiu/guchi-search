# QA Plan: 新資料庫 — 初測

**測試標的**：https://sear.newfolderla.com（production）
**Backend**：https://backend-production-b729.up.railway.app
**測試範圍**：搜尋體驗、首頁、單集頁、校對 UI（不送出）、錯誤處理、a11y、響應式
**測試環境**：production / Playwright Chromium / macOS 15
**預計耗時**：1 輪（10-15 個 case，P0 + 高價值 P1）
**日期**：2026-04-29

## Feature Map

- 首頁
  - Hero（標題、統計）
  - 搜尋框 + scope toggle（4 種範圍）
  - 7 日熱門關鍵字
  - 校對貢獻榜
  - 集數列表 + 分頁 + 排序（最新/最舊）
  - 載入狀態 / 錯誤狀態
- 搜尋
  - 一般 CJK 中文
  - 罕見字 / 部分匹配
  - 空字串 / 超長 / 特殊字元 / emoji / 英文 / 簡繁
  - 結果分類顯示（內容匹配 / 標題匹配 / 近似）
  - 結果展開／收合
- 單集頁
  - Sticky audio player
  - 時間戳跳播
  - URL hash scroll + highlight
  - 逐字稿載入
  - 校對 UI（hover 鉛筆、開啟編輯框 — **不送出**）
  - 404（不存在的 episode id）
- a11y / 響應式
- API（GET only）
