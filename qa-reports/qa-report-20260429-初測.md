## ❌ Bug

### BUG-01 [P1] 點熱門關鍵字觸發搜尋後，搜尋框沒同步顯示新關鍵字

- **環境**：Chromium / macOS / production
- **重現步驟**：
  1. 開 https://sear.newfolderla.com
  2. 在搜尋框輸入 `OpenAI` 按搜尋（input 顯示 OpenAI、結果顯示 19 集）
  3. 滾到熱門關鍵字區，點「黃國昌」
  4. 結果列表切換成「黃國昌 116 集」，但 **input 框仍顯示「OpenAI」**
- **預期**：點熱門關鍵字後，搜尋框 input 應同步顯示該關鍵字
- **實際**：input 內容沒變，使用者看到「結果是黃國昌 116 集」但「框裡寫 OpenAI」
- **Console error**：無
- **Network**：`/api/search?q=黃國昌` 200 OK
- **影響**：UX 混淆。使用者無法直接修飾當前搜尋（例如想加字、想記錄當前 query），且若按 Enter 會搜舊字串
- **建議修法**：`frontend/src/components/SearchBar.tsx` 把 SearchBar 改成 controlled component（query 由 parent 管理），或加：
  ```ts
  useEffect(() => { setQuery(initialQuery); }, [initialQuery]);
  ```
- **回歸 spec**：`qa-reports/regression/bug-search-input-not-synced.spec.ts`

### BUG-02 [P2] 簡體字 query 找不到資料庫內已轉繁的內容

- **環境**：production backend
- **重現步驟**：
  1. `curl "$BACKEND/api/search?q=电脑"` → 2 集
  2. `curl "$BACKEND/api/search?q=電腦"` → 393 集（差 196 倍）
  3. 同樣現象：「电视」2 集 vs「電視」378 集
- **預期**：使用者輸入簡體字應與繁體字搜出近似結果（資料已 OpenCC s2t 為繁體）
- **實際**：差異巨大；簡體輸入法的使用者錯失絕大多數匹配
- **Console error**：無（backend 200 OK，純 UX）
- **影響**：使用簡體輸入法、或從中國/海外貼簡體查詢的使用者體驗差。雖非主要受眾，但影響存在。
- **建議修法**：`backend/app/api/search.py` 在送 Meilisearch 前對 query 套 `opencc.OpenCC('s2t')` 一次（已有套件）
- **回歸 spec**：`qa-reports/regression/bug-simplified-chinese-search.spec.ts`

## ⚠️ 警示

### WARN-01 [低] favicon.ico 404
- 進首頁就有 1 條 console error：`GET /favicon.ico 404`。建議放一個 favicon 或在 `app/layout.tsx` 設 `metadata.icons` 把 console 清掉。

### WARN-02 [低] Hero 統計文字 spacing 略亂
- 顯示為「792 集已轉錄　·2,521,334 段文字可搜尋」
- 中間 `·` 與後方數字間沒空格（半形點貼著數字），但前面有全形空白。視覺上略不對稱。
- 位置：`frontend/src/app/page.tsx:151-153`

### WARN-03 [中] 後端 highlighted_text 未 HTML-escape，存在潛在 stored XSS 路徑
- `backend/app/api/search.py:209` 直接把 Meilisearch `_formatted.text` 作為 `highlighted_text` 回傳，前端 `dangerouslySetInnerHTML` 渲染。
- 目前 transcript 由 Whisper 產生，幾乎不可能含 `<` `>` `&`，實務風險低。
- 但如果未來：
  1. 校對者送出含 HTML 的修正字串並被批准 → stored XSS
  2. RSS 抓到的 episode_title 含 `<` `&`（episode_title 也被索引、也會出現在 highlight）→ stored XSS
- **建議**：在 `_format_hit` 把 highlighted 字串先 escape 後再插 `<mark>` tag（`html.escape` + 把 escape 後的 `&lt;mark&gt;` 換回 `<mark>`），或改前端不用 `dangerouslySetInnerHTML`，自己解析 mark 範圍。

### WARN-04 [低] 搜尋結果有集數沒有日期顯示
- 「呱吉」搜尋第 8 個結果（直播 8 處 大家好我是呱吉喔）卡片中沒顯示日期。可能該集 `published_at` 是 null。檢查 `backend.../app/services/rss_parser.py` 是否有過 RSS 缺日期的集數。

### WARN-05 [a11y 中] 校對鉛筆按鈕只在 hover 時可見
- `.nrk-line__edit` 預設 opacity 0 / hover 顯示。
- 鍵盤使用者（Tab 進來）和觸控使用者看不到；觸控可以點，但發現不到該功能存在。
- **建議**：focus 時也讓它顯示（`:focus-within` on `.nrk-line`、或直接 always visible 配淺色）。
